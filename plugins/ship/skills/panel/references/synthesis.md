# Panel synthesis

## Evidence rules

- Count one completed, valid, independent response per requested model.
- Count each model once per finding, regardless of how many lenses identify it.
- Keep the coordinator's analysis outside the agreement count.
- Use only completed independent responses in the agreement denominator.
- Describe agreement as a response count; agreement alone does not establish correctness.
- Treat observed duplicate-model routing as one independent model and mark the required panel incomplete.
- Mark routing `unverified` when harness or gateway evidence is absent.
- Separate independent findings from follow-up verification influenced by shared findings.
- Preserve dissent, assumptions, unique findings, and absence of concerns.
- Give a single P0 priority over a widely shared P3.

Use the majority seat verdict, with the more cautious verdict for a tie.
Keep unresolved P0 findings prominent in the decision and action plan.
Mark the verdict `provisional` for an incomplete panel.
Use `UNAVAILABLE` when zero valid responses complete; provide the failure and recovery action.
Never represent an incomplete panel as full consensus or successful completion.

## Report contract

Lead with the panel verdict and the decision the user must make.
Include the following sections, with empty sections omitted only when their absence is explicit elsewhere.

1. **Panel**: challenge, type, tier, lenses, date, evidence scope, and completed/required seat count.
2. **Seats**: requested model, observed model and evidence, status, and verdict for every required seat.
3. **Consensus findings**: findings from at least two independent completed models, ordered by priority.
4. **Tensions**: opposing positions, model attribution, evidence, and the question or test that resolves each tension.
5. **Unique findings**: single-model concerns with priority and evidence.
6. **Risk assessment**: shared dimension averages and source counts; label single-source dimensions.
7. **Assumptions and blind spots**: missing evidence, unavailable seats, incomplete lenses, and consequences for the decision.
8. **Action plan**: concrete next actions ordered by priority, with agreement counts and acceptance conditions.

For each finding, include the supporting models, `supporting/completed` response count, evidence, impact, and recommendation.
Present disagreement faithfully and identify where human judgment is necessary.
Separate the coordinator's recommendation from the panel's positions.
Retain full seat reports in native agent context for follow-up.
Include full reports when the user asks for them.
